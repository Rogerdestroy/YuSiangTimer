# YSTimer 計時器

單一檔案（`index.html`）的網頁計時器合集，免安裝、免登入，用 GitHub Pages 架設並嵌入 Google 協作平台。

| 網址後綴 | 計時器 | 怎麼用 |
|---|---|---|
| `#guess` | 猜秒數 | 看不到時間，憑感覺在 5／10／30／60 秒按停 |
| `#stopat` | 精準停錶 | 碼錶飛快地跑，挑戰剛好停在 3／5／10 秒 |
| `#reaction` | 反應力測驗 | 畫面變綠立刻點，測反應毫秒數 |
| `#clicker` | 手速連點 | 5／10／30 秒內能點幾下 |
| `#rhythm` | 節拍感 | 聽 4 拍後自己點 8 下，算節奏誤差 |
| `#schulte` | 數字方格 | 3×3～5×5 依序點 1→25 |
| `#bomb` | 傳炸彈 | 課堂傳物遊戲，隨機時間爆炸 |
| `#gym` | 重訓計時器 | 開始後，做完一組點休息秒數 → 自動倒數 → 休息完自動回到訓練 |
| `#interval` | 間歇訓練 HIIT | 選 Tabata 等組合或自訂，運動／休息自動循環 |
| `#pomodoro` | 番茄鐘 | 選 25/5、50/10、15/3，專注與休息自動輪替 |
| `#breath` | 呼吸放鬆 | 方塊呼吸、4-7-8、4-6，跟著圓圈呼吸 |
| `#teach` | 試教計時器 | 總時間與各步驟時間（分＋秒），上課時逐步顯示，結束看預計 vs 實際 |
| `#countdown` | 倒數計時 | 一鍵 1～30 分或自訂分秒 |
| `#speech` | 發表計時 | 綠→黃→紅燈號，快到一聲鈴、時間到兩聲鈴 |
| `#exam` | 考試時鐘 | 投影用大時鐘，結束前 15、5 分鐘響鈴 |
| `#kitchen` | 廚房計時 | 泡麵、煮蛋、泡茶等一鍵開始，可同時多個 |
| `#chess` | 棋鐘 | 下棋、桌遊、辯論輪流計時 |
| `#stopwatch` | 碼錶 | 0.01 秒、分圈 |

快捷鍵：空白鍵 開始／暫停、F 全螢幕。設定只存在使用者自己的瀏覽器。

## 嵌入 Google 協作平台

插入 → 嵌入 → 依網址，貼上 `https://rogerdestroy.github.io/YuSiangTimer/`（可加 `#teach` 等後綴），選「整個頁面」。
嵌入框裡無法全螢幕時，按右上角 ↗ 在新分頁開啟。
